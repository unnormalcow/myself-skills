# zf-businessprocess

用于把中纺/福田现场调研录音转文字、会议纪要等材料，转换为：

1. 16:9高清“端到端总览 + 详细泳道”业务流程图；
2. 16:9高清数据资产目录L1-L3图。

核心特点：
- 严格基于调研原文，不创造节点；
- 上下版式约1:5；
- 支持业务异常、返工、判断、系统、纸质、Excel、邮件等现状表达；
- L3以“人、事、物”及可管理数据对象为核心识别；
- 保持中纺/福田项目已确认的蓝白咨询风格；
- 字体锐化、quality=high、单图独立生成；
- **最终直接调用生图能力输出图片，不再额外交付文字版结果。**

主规则见 `SKILL.md`。
