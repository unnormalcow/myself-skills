# 公文排版格式标准（数据资产目录建设调研问卷）

> 适用范围：所有由本 skill 生成的「数据资产目录建设调研问卷」Word 文档，须严格对齐客户提供的范本《福田公司销售部门数据资产目录建设调研问卷 V1.0》的排版规范。

## 1. 字体与字号

| 元素 | 字体 | 字号 | 加粗 | 说明 |
|------|------|------|------|------|
| 大标题（公司+部门+问卷名） | **黑体** | 22pt | 是 | 居中 |
| 副标题（——面向…——） | **楷体** | 14pt | 否 | 居中 |
| 元信息（编制单位/版本/日期/密级） | 仿宋 | 12pt | 否 | 居中 |
| 一级标题 一、二、三…（Heading 1） | **黑体** | 16pt | 是 | 段前12 段后6 |
| 二级标题 3.1 3.2…（Heading 2） | **黑体** | 14pt | 是 | 段前12 段后6 |
| 三级标题 4.1 4.2…（Heading 3） | **黑体** | 12pt | 是 | 段前12 段后6 |
| 正文段落 | 仿宋 | 12pt | 否 | 行距 1.5 倍、段后 3pt |
| 调研题目（4.1.1、…） | 仿宋 | 12pt | **是** | 题目加粗 |
| 编号 (一)(二) / 1. 2. 3. | **黑体** | 12pt | **是** | 分类与小标题用黑体加粗 |
| 枚举 (1)(2)(3) | 仿宋 | 12pt | 否 | 段内列举项用仿宋 |
| 【说明】提示 | **楷体** | 12pt | 否 | 非斜体 |
| 作答空行（答：____） | 仿宋 | 12pt | 否 | 继承正文 |
| 勾选/排序选项（□ / （  ）） | 仿宋 | 12pt | 否 | |
| 表格表头 | 仿宋 | 9pt | **是** | 浅蓝底（D9E2F3） |
| 表格内容 | 仿宋 | 9pt | 否 | |

> 字体名必须用中文名：黑体、仿宋、楷体（通过 rFonts 的 eastAsia 属性设置，否则中文会落到西文字体）。

## 2. 页面与段落
- 页边距：左右 3.17cm，上下 2.54cm（与范本一致）。
- 目录「目  录」为 Heading 1 居中；目录项为仿宋 12pt、段后 4pt。
- 目录序号层级：一、二、三、四、五 为顶级；4.1~4.8 在「四、调研问题」下**缩进**列出。

## 3. 分页符（关键）
- **封面独立成页**：封面（大标题+副标题+元信息）与目录之间插 1 个分页符，目录另起一页。
- **仅大章节分页**：每个一级章节（一、二、三、四、五）前插分页符（共 5 个）。
- **子章节不分页**：4.1~4.8 等三级子章节**不插分页符**，连续排在所属一级章节（如「四、调研问题」）之下。
- 总计 **6 个分页符**：封面→目录、目录→一、一→二、二→三、三→四、四→五。
- ❌ 常见错误：给 4.1/4.2 等子章节也加分页符（会使每节另起页，违背客户要求）；封面与目录挤在同一页。

## 3.1 缩进（关键）
- **正文 / 题目（4.1.1、） / 编号（一）（二）1.2.3. / 枚举 (1)(2)(3) / 答行 / 【说明】**：首行缩进 **2 字符（24pt，12pt 字号下）**。
- **一级~三级标题（一、/3.1/4.1）与目录项**：首行缩进为 0（不缩进）。
- 居中元素（大标题、副标题、元信息、结尾语）无需缩进。

## 4. 表格（4.6.1 核心数据清单）
- 表格样式：`Light Grid Accent 1`（缺省模板无此样式时回退 `Table Grid` + 表头浅蓝底）。
- 列：数据类别 | 具体内容 | 管理位置（系统/文件） | 规范情况。
- 表头仿宋 9pt 加粗 + 浅蓝底；内容仿宋 9pt。

## 5. 八维框架与领域映射
生成问卷时套用八维框架（业务概况 / 核心对象主数据 / 订单与执行 / 计划·排产·结算 / 数据与报表 / 标准化主数据 / 数据安全 / 痛点优化），并按目标业务域替换核心对象与流程：
- 销售域：核心对象=客户，流程=合同→订单→发货→开票→收款
- 生产域：核心对象=物料/BOM，流程=计划→工单→投料→报工→完工入库（第4维替换为「生产计划·排产·委外」）
- 采购域：核心对象=供应商，流程=请购→订单→收货→发票→付款
- 财务域：核心对象=科目/核算项，流程=凭证→记账→报表→合并
