## 一、项目背景（根据项目实际填写）
简述行业/政策背景、本业务域定位、当前数据管理存在的主要问题（完整性/准确性/时效性问题、链路断点、标准不统一、分析手段有限等）。

## 二、项目目标（"摸清家底、打通链路、建立标准、提升效能"思路）
1. 全面摸清{业务域}数据家底，形成数据资产清单
2. 打通{核心流程}全链路数据流转，识别断点与盲区
3. 规范{核心对象}主数据管理，识别编码/属性/更新问题
4. 识别信息系统覆盖缺口
5. 夯实数据治理基础，为制度与质量监控提供依据

- 3.2 调研范围（业务领域、产品/市场维度、相关信息系统）

- 3.4 填写说明（业务语言作答、系统可化名、不确定标注"不清楚/不适用"）

## 四、调研问题（八维框架）

### 4.1 {业务域}业务概况
- 4.1.1 目前的组织架构如何？按什么维度分组？各组人员规模？
- 4.1.2 目前使用哪些信息系统支撑日常工作？列出系统名称及主要功能。
- 4.1.3 从{流程起点}到{流程终点}的全流程中，哪些环节在系统内完成，哪些依赖手工/纸质？
- 4.1.4 不同{产品线/对象类型}的业务特点和流程是否有明显差异？
- 4.1.5 日常工作使用系统的同事规模？系统响应能否满足业务需要？

### 4.2 {核心对象}管理与{关键单据}
- 4.2.1 目前有多少个活跃{核心对象}？不同{对象类型}群体差异及数量？
- 4.2.2 {核心对象}主数据包含哪些信息？在哪个系统维护？
- 4.2.3 主数据的创建/变更/冻结是否有规范审批流程？由谁执行？是否出现过同一对象多编码或信息不一致？
- 4.2.4 {对象}信用/额度管理：是否设置额度？超限有无审批？逾期有无预警？
- 4.2.5 {关键单据}如何管理（系统/线下）？条款能否被后续环节引用？长期框架与单笔管理方式差异？
- 4.2.6 内/外（销/购）对象管理差异？相关单证目前如何管理？是否与业务单据关联？

### 4.3 {业务订单}与{执行}流程
- 4.3.1 订单创建流程：手工/导入/对接？耗时与步骤？有无内部审核？
- 4.3.2 不同{对象类型}订单处理流程差异？
- 4.3.3 执行跟踪：如何传递至下环节？有无延迟遗漏？能否实时了解进度？变更有无版本追溯？
- 4.3.4 {执行动作}管理：通知单如何生成？谁操作？数据是否实时更新？有无"先执行后补单"？
- 4.3.5 批次/序列跟踪：是否记录批号？能否通过订单追溯到生产/来源批次与质量记录？
- 4.3.6 勾选执行中常见问题（订单变更难追溯 / 交期延误 / 库存不足 / 分批麻烦 / 数据更新不及时 / 内外数据不一致 / 其他）

### 4.4 {定价}与{结算/开票}
- 4.4.1 定价策略如何管理？价格在哪维护？不同规则如何管理？变更能否及时更新？
- 4.4.2 折扣与附加费如何处理？是否在单据中体现？
- 4.4.3 开票/结算流程：在哪个系统开具？依据是什么？有无长期未结算已执行业务？
- 4.4.4 内/外（销/购）在结算处理上的差异？

### 4.5 {业务域}数据与报表
- 4.5.1 日常需要哪些报表/统计？系统直接获取还是手工整理？
- 4.5.2 系统数据能否满足分析需求？是否存在"数据有但出不来"或"不全不准"？
- 4.5.3 {资金/账项}管理：对账催收如何进行？能否方便查询余额/账龄/回款？有无长期逾期？原因？
- 4.5.4 对核心数据进行重要程度排序（1~N，1 最关键）

### 4.6 数据标准化与主数据
- 4.6.1 核心数据清单表（数据类别 | 具体内容 | 管理位置 | 规范情况），至少包含：
  核心对象主数据 / 合同数据 / 订单数据 / 执行数据 / 发票结算数据 / 应收应付数据 / 价格数据 / 信用额度数据
- 4.6.2 主数据管理现状：
  - 编码规则是否统一？是否存在同一对象多编码？如何解决？
  - 物料/对象编码规则是否统一？查找是否方便？
  - 是否已发布相关主数据管理规范？（勾选：对象/物料编码规范、定价办法、合同管理规范、数据质量管理办法等）

### 4.7 数据安全管理
- 4.7.1 用户权限如何管理？岗位权限划分是否合理？离职账号是否及时清理？
- 4.7.2 价格/敏感信息是否做访问控制？机制是否合理？
- 4.7.3 联系方式/银行账户等敏感数据是否保护？是否担心泄露？
- 4.7.4 电子单据是否有集中存储与权限管理？是否散落个人电脑/共享文件夹？
- 4.7.5 关键操作（价格修改/额度调整/订单变更）是否有操作记录？能否追溯人/时间/内容？
- 4.7.6 勾选已实施的安全管控（密码策略 / 岗位权限 / 敏感操作审批 / 操作日志 / 权限复审 / 备份恢复）

### 4.8 使用痛点与优化需求
- 4.8.1 数据管理最大困难 Top3（客户信息不准 / 编码混乱 / 订单效率低 / 数据分散 / 手工报表 / 单据混乱 / 价格不透明 / 数据对不上 / 跨部门不互通）
- 4.8.2 最希望实现的一项改进？
- 4.8.3 一句话评价当前数据管理整体水平（满分 10 分）：___分
